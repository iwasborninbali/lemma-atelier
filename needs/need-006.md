- **источник:** lem-001 §граница: на свидетелях A280537 (`~/saturation/certs/a280537/`, n = 6: 16 точек; n = 7: 17 и 18 точек) удаление точки
  снимает до |S| − 2 убийц клетки (Δ_p κ³(q) = 14, 15, 16), и лемма о κ не применима; при этом ни одна клетка не оживает
  (`~/saturation/slack/night_2026-09-02/vtora/kappa_cube4.txt`, поле «оживлений»: 0, 0, 0). Наблюдение первого солвера 21.08
  («удаление любой точки оживляет ровно одну клетку», 116 проверок без исключений — `~/saturation/docs/research/rigidity.md`) стоит без причины.
- **вычисление, которому нужно общее утверждение:** страты CP-SAT для A280537 (запуск 3.09) дадут стратные оптимумы; хотим за секунды говорить,
  улучшаем ли свидетель заменой, и знать, когда «нет замены» — свойство оптимума, а когда — любой максимальной конфигурации.
- **чего не хватает (UNSPECIFIED):** причина жёсткости при запрете «4 в плоскости». Что уже есть: (а) для пустой q, не коллинеарной ни с какой
  парой точек S, любые два убийцы делят ≤ 1 точку (доказано, lem-001 §граница) ⇒ убийцы через одну точку образуют паросочетание на S∖{p},
  их ≤ ⌊(|S|−1)/2⌋; (б) клетки, коллинеарные с парой точек S, имеют κ³ ≥ 16 (медиана 19–22) — они не хрупкие; (в) хрупкие клетки (κ³ = 3…5)
  есть у всех трёх свидетелей, и у них max_p(доля убийц через p) ≤ 0.6, у всех клеток ≤ 0.9 (`kappa_cube4_lowk.txt`). Не хватает
  утверждения, почему у хрупких клеток убийцы не проходят через одну точку.
- **гипотеза (conj-006):** жёсткость — свойство оптимумов, а не максимальности: среди случайных максимальных конфигураций без четырёх
  компланарных (жадный рост) при n = 6 и n = 7 не меньше 30 % НЕжёстки (есть точка, удаление которой оживляет чужую клетку), тогда как все
  известные оптимумы (16 при n = 6; 18 при n = 7) и максимальный 17 при n = 7 жёстки. Ставка — числом в `moves/ledger.jsonl` (см. строку
  `prediction` от 2026-09-03, case «жёсткость A280537: оптимумы против случайных максимальных»); проигрыш — доля нежёстких среди случайных
  максимальных < 10 % (тогда жёсткость — общее свойство максимальности в этом запрете, и причину надо искать в геометрии плоскостей).

**Уточнённая гипотеза (conj-006b):** у максимальных конфигураций без четырёх компланарных при n = 6, 7 жёсткость ⟺ |S| ≥ a(n) − 1.
Проверка: (а) стратные оптимумы A280537 коллеги (CP-SAT, запуск 3.09) — размеры a(n) − 1 … a(n) должны быть жёстки, меньшие — нет;

Чего не хватает по-прежнему — причины: почему у почти-оптимальных S у каждой хрупкой клетки убийцы не проходят через одну точку.
Кандидат объяснения: у почти-оптимума все пустые клетки лежат на многих плоскостях троек (κ³ велико: медиана 9–10, минимум 3), а у
случайной максимальной κ³ малы (много клеток с κ³ = 1–2), где один убийца через p решает всё — измерить распределение κ³ у обеих популяций.
