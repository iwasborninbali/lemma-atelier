Проверка: (а) стратные оптимумы A280537 коллеги (CP-SAT, запуск 3.09) — размеры a(n) − 1 … a(n) должны быть жёстки, меньшие — нет;
(б) максимальные конфигурации промежуточных размеров (14–16 при n = 7) — получить локальным поиском, ожидание: нежёстки все до 16, жёсток 17.
Чего не хватает по-прежнему — причины: почему у почти-оптимальных S у каждой хрупкой клетки убийцы не проходят через одну точку.
Кандидат объяснения: у почти-оптимума все пустые клетки лежат на многих плоскостях троек (κ³ велико: медиана 9–10, минимум 3), а у
случайной максимальной κ³ малы (много клеток с κ³ = 1–2), где один убийца через p решает всё — измерить распределение κ³ у обеих популяций.

## Измерение по кандидату объяснения (03.09, втора) — ставка нарушена по числу, направление верно

`rigid_kappa_dist.py` (по 100 случайных максимальных): доля пустых клеток с κ³ ≤ 2 — 10.8 % (n = 6) и 7.5 % (n = 7) при заявленных ≥ 15 %
(у оптимумов 0 %: min κ³ = 3); медиана κ³ — 5 против 9–10 у оптимумов. Оживающие клетки распадаются на **два горба**: κ³ = 1…3 (мало убийц)
и κ³ = 8…12 ≈ |S| − 2 — клетки, коллинеарные с парой {p, s}, у которых ВСЕ убийцы содержат эту пару (механизм границы lem-001), и удаление p
оживляет их разом. У оптимумов коллинеарные клетки имеют κ³ ≥ 16 — есть убийцы помимо троек через пару.

**Уточнённая формулировка нужды:** жёсткость почти-оптимума держится на двух условиях — (A) нет пустых клеток с κ³ ≤ 2 (двойное покрытие
в слабой форме: два убийцы без общей точки уже достаточны? — нет: нужно, чтобы не все убийцы шли через одну точку); (B) каждая пустая клетка,
коллинеарная с парой точек S, имеет хотя бы одного убийцу, не содержащего эту пару. Гипотеза-лемма (conj-006c): для максимального S без четырёх
компланарных, S жёстко ⟺ (A′) у каждой пустой клетки убийцы не имеют общей точки. (A′) — тавтологическая переформулировка жёсткости;
содержательный вопрос — почему (A′) выполняется у оптимумов: измерить на стратных оптимумах A280537 (страты коллеги) число клеток, где
максимальная доля убийц через одну точку ≥ 0.9, как функцию |S| − a(n).

## conj-006d (03.09, втора) — держится: у оптимумов нет клеток, уязвимых по паре

Определение: пустая q «уязвима по паре», если q коллинеарна с парой {p, s} ⊂ S и каждая тройка-убийца q содержит {p, s} (удаление p оживляет q).
`~/saturation/slack/night_2026-09-02/vtora/conj006d_check.py`: у 13 (n = 5, c03 и c06), 16, 17, 18 — таких клеток **0**; у нежёсткого стратного 11
(n = 5, c17) — 2; у случайных максимальных — 71 % (n = 6) и 75 % (n = 7) конфигураций имеют хотя бы одну. Итог: нежёсткость имеет два механизма —
клетки с κ³ ≤ 2 и уязвимость по паре — и у оптимумов нет ни того, ни другого. Открытым остаётся доказательство: почему у оптимума
коллинеарная с парой клетка всегда имеет убийцу вне пары (гипотеза-лемма conj-006e: если S оптимально и q коллинеарна с {p, s}, то
существует тройка S∖{p, s}… компланарная с q; иначе S∖{p} ∪ {q} — другой оптимум, и оптимумы соединены заменой — а по conj-006b они
жёстки; то есть conj-006e равносильна жёсткости оптимумов и не является независимым объяснением; нужна другая идея).

## Закон вместо особого свойства (03.09, ставка держится): доля заменяемых точек падает с размером

`rigid_vs_size.py` (200 случайных максимальных, жадный рост, прямой счёт), `rigid_vs_size_n7.txt`, `rigid_vs_size_n6.txt`. Средняя доля
точек, удаление которых оживляет чужую клетку: n = 7 — |S| = 12: 0.972 (18 конф.), 13: 0.886 (106), 14: 0.655 (66), 15: 0.350 (8),
16: 0.125 (1); n = 6 — 10: 1.000 (9), 11: 0.919 (64), 12: 0.763 (97), 13: 0.459 (30). Падение примерно вдвое на каждую точку у верхнего
края; экстраполяция к 17–18 при n = 7 даёт ≈ 0.03–0.06 заменяемых точек — то есть жёсткость оптимумов (17, три 18; 16 при n = 6) —
хвост общей тенденции «чем плотнее максимальная конфигурация, тем меньше у неё дефектов», а не отдельное свойство оптимальности.
Оговорка: при 15–16 выборки малы (8 и 1). Нужда переформулирована: доказать монотонность (или оценку) E[заменяемых | |S| = m] по m —
кандидат на механизм: у плотной S каждая пустая клетка убита многими тройками (Σ_q κ³(q) = Σ по тройкам числа клеток их плоскости растёт
как C(m, 3)), и убийцы через одну точку составляют долю ≈ 3/m всех убийц клетки, так что «все убийцы через p» становится редким событием.
