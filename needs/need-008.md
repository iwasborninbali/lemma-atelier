# need-008 — вывести абсолютный спектр направлений из ограничения «нет трёх на прямой»

- **источник:** ночь 2→3.09 (коллега, `vtora/abs_spectrum_check.txt`): c_v = (пар примитивного направления v на решение)/n — константы по
  n = 19…57 по всей базе Фламменкампа: (1,1) 0.7306, (1,2) 0.5633, (1,3) 0.4545, (2,3) 0.4095, (1,4) 0.3744, (1,5) 0.3073, (2,5) 0.2846,
  (3,4) 0.3043; κ = c_(1,1). Владелец 3.09: «если хоть одно из измерений выведется из ограничения — балл 3»; вектор дня.
- **вычисление:** сравнение с нуль-моделями; цель — модель без подгоночных параметров, дающая все восемь чисел и порядок.
- **чего не хватает:** вывод, а не измерение. Нуль-модель фиксированных маргиналов даёт c_v^null = 1.27 / 0.75 / 0.51 / 0.43 / 0.37 / 0.28 /
  0.26 / 0.29 (n=20; lem-004 даёт точное p2, p3), то есть истощение 0.58 / 0.75 / 0.89 / 0.94 / 1.01 / 1.09 / 1.11 / 1.06 — короткие
  направления истощены, длинные слегка обогащены.
- **шаг 1 (3.09, opus, ставка — нарушена):** парная модель первого порядка (пара направления v выживает с весом (1 − p3/p2)^L, L — прочие
  клетки её прямой; перенормировка на 2n² − 3n) ПЕРЕистощает короткие направления: (1,1) 0.40 против 0.73, порядок (1,1)/(1,2) неверен;
  длинные направления — в 10 %. Исключения вдоль длинной прямой не независимы.
- **шаг 2 (3.09, opus, модель постфактум — проверка вслепую поставлена):** «модель прямых»: для направления v разложить 2n точек по
  прямым этого направления с ограничением ≤ 2 на прямой и весами C(L_i, x_i) (клетки равновесны; строки/столбцы не учитываются);
  E[число прямых с ровно 2 точками] через производящую функцию ∏(1 + L_i t + C(L_i,2) t²) — коэффициент при t^{2n}; затем ОДНА
  перенормировка Z на точное число трансверсальных пар 2n² − 3n (сумма по всем направлениям; Z = 1.203 при n=20, 1.163 при n=30,
  1.139 при n=40). Результат (n=20): 0.764 / 0.563 / 0.433 / 0.377 / 0.343 / 0.278 / 0.254 / 0.274 — отношения к измеренным
  1.045 / 0.999 / 0.952 / 0.920 / 0.916 / 0.905 / 0.894 / 0.900; n=30: 1.018 … 0.926; **порядок всех восьми совпадает**. Без подгоночных
  параметров. Остаток −5…−10 % на длинных направлениях — вероятно, отсутствие маргиналов строк/столбцов в весах.
- **гипотеза (conj-008):** спектр направлений — функция распределения длин прямых каждого направления при ограничении «≤ 2 на прямой»;
  измерение вслепую семи новых направлений (ставка в ledger 3.09, предсказания n=30: c(1,6) = 0.244, c(1,7) = 0.211, c(2,7) = 0.198,
  c(3,5) = 0.244, c(4,5) = 0.222, c(1,8) = 0.183, c(3,7) = 0.185; ±12 % — 60 %) — измеряет коллега.
- **кандидат леммы (lem-005):** точная формула E[#прямых с двумя точками] в модели прямых (доказуемо: производящая функция) + утверждение
  о перенормировке; «использование» — восемь констант базы. Граница: сама модель не даёт κ как функцию n (константность по n у модели
  выполняется с дрейфом 3–8 %, у базы — в 1 %).

  (бриф 14 — прайор-арт) и одно письмо Ахиму с PDF.
