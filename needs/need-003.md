# need-003 — условный Гай–Келли: выпуклость E[T | профиль чётности] как явный многочлен

- **источник:** ночь, коллега: наклон exp(−E[T | профиль]) объясняет 85–90 % показателя чётности (дисперсия 0.47 ± 0.06 против
  0.42); E[T | k] выпукло с минимумом при k = n/2 (n=20: 64.95 / 62.33 / 61.47 / 62.41 / 64.94 при k = 8…12).
- **вычисление:** хотим E[T | профиль по классам mod 2] в замкнутой форме — кубический многочлен по k (направления (odd,odd)
  соединяют классы равной плотности → вклад ∝ k³ + (n−k)³; смешанные — ∝ k(n−k)).
- **чего не хватает:** точные коэффициенты через число прямых каждого типа чётности; доказательство; тот же результат для mod 3.
- **гипотеза (conj-003):** E[T | k] = A(n)·[k³ + (n−k)³]/n³ + B(n)·k(n−k)/n² + C(n) с явными A, B, C; при n=20 ΔE(12 против 10) = 3.5 ± 0.3.

- **шаг 1 (3.09, opus):** lem-004 — безусловное среднее в замкнутой форме: E[T] = c(n)·τ(n)/(6·C(n,3)²), τ = C(2n,3) − 4n² + 6n,
  c(n) = A000938(n) − 2n·C(n,3); точный перебор n = 3…6 совпал; наивная модель «2n клеток равномерно» завышает только за счёт осевых троек, а без них
  занижает на 3/n (13 % при n = 20) — противник №1/№2 по lem-004. Профиль чётности — не инвариантен
  под S_n × S_n, поэтому E[T | профиль] требует меньшей группы (перестановки строк и столбцов внутри классов чётности) и разбиения
  трансверсальных троек на орбиты по образцу чётностей — это и даст коэффициенты A, B, C conj-003 (шаг 2, открыт).

- **шаг 2 (3.09, opus, точный перебор n = 4, 5, 6, дроби; ставка в ledger — держится/нарушена):** таблицы E[T | k], k = число точек в
  клетках (нечётная строка, нечётный столбец): n=4: 6, 9/4, 12/7, 9/4, 6; n=6: 50/3, 274/27, 5732/891, 2360/441, 5732/891, 274/27, 50/3;
  n=5: 158/27, 365/99, 668/159, 301/45, 38/3. **Симметрия k ↔ n−k при чётном n точна** (отражение строк r ↦ n−1−r переводит нечётные
  строки в чётные, сохраняет коллинеарность и маргиналы; при нечётном n симметрии нет — n=5 несимметрично), **минимум в k = n/2** —
  подтверждено. **conj-003 в заявленной форме мертва:** k³ + (n−k)³ = n³ − 3n·k(n−k), поэтому «кубика» A[k³+(n−k)³]/n³ + B·k(n−k)/n² + C —
  это квадратика a + b·k(n−k) с двумя параметрами, и она НЕ точна: n=4, k=2 — предсказание 1 против точного 12/7; n=6, k=2 — 842/135
  против 5732/891. E[T | k] — не многочлен по k этого вида; следующий шаг (если нужен): точная формула через распределение нагрузок
  нечётных строк при данном k (гипергеометрическое смешение), либо честно оставить как измерение. Выпуклость при n=20 ночью была
  квадратичной по виду — потому и «кубика» казалась подходящей.
