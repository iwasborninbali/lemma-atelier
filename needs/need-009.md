# need-009 — конструкции по гиперболам не достигают 2n: что доказано в теореме окна и чего не хватает для приложения

- **источник:** заметка «HJSW window» (Zenodo concept 10.5281/zenodo.22063297, v1.17; `~/saturation/paper/hjsw_window.tex`): точный максимум
  no-three-in-line подмножества модулярной гиперболы xy ≡ c (mod p) в окне 2p×2p — 3(p−1), число максимумов 9^s, ЛП-релаксация точна;
  для любого 2p×2p окна максимум ≤ 3(p−1) (12n₂ + 10n₁ + 8n₀ + 6s); две гиперболы H(1) ∪ H(−1) — ≤ (11/3 + o(1))(p−1) и далее (3.4482 + o(1))(p−1);
  кубические графы — ≤ (4/3 + o(1))·2p. План владельца 03.09: прогнать главную теорему через ателье и написать приложение «конструкции по
  гиперболам не достигают 2n» — второй arXiv-пакет.
- **вычисление, которому нужно общее утверждение:** нижняя граница 3n/2 − o(n) (HJSW 1975) — единственная общая; хотим утверждение вида «ни одна
  конструкция из точек фиксированного числа модулярных гипербол в окне 2p×2p не даёт (2 − ε)·2p» с явным ε, чтобы честно сказать, какие
  алгебраические конструкции по модулю p исключены (замечание Грина к задаче 72) и какие — нет.
- **чего не хватает (UNSPECIFIED):** (1) для одной гиперболы — всё доказано (lem-006: барьер ровно 3/2 в единицах 2p, с точностью до −3);
  (2) для двух гипербол — доказано < 11/6 (и 1.7241 численно), но не для произвольной пары H(k), H(k′) в произвольном окне (потенциальное покрытие
  даёт выигрыш лишь при не слишком неровном распределении восьмиточечных прямых по циклам; для примитивных k — c√p/log⁵p); (3) для
  объединения r ≥ 3 гипербол — только вычислительные наблюдения (§«beyond»: выигрыш O(1) над 3(p−1) ожидается, не доказан); (4) другие кривые
  (кубики — да, ≤ 4/3·2p; коники — только сдвинутые гиперболы достигают 3(p−1); более высокие степени — нет).
- **гипотеза (conj-009):** для всякого r и всякого окна 2p×2p максимум законного подмножества объединения r модулярных гипербол
  H(c₁) ∪ … ∪ H(c_r) не превосходит 3(p−1) + C(r) с константой, не зависящей от p (владельческая ожидаемая форма из §beyond); минимальная
  проверяемая ставка — для r = 2, всех пар (c₁, c₂) и всех окон при p ≤ 13 точный максимум ≤ 3(p−1) + 6.
- **кто возьмёт:** авторы приложения к заметке (владелец, ателье); те, кто ищет алгебраические конструкции для no-three-in-line по модулю p
  (Грин, задача 72; Kovács–Nagy–Szabó 2025) — что именно исключено.
