# need-007 — масса убийц: почему у плотных конфигураций без четырёх компланарных исчезают хрупкие клетки

- **источник:** need-006 (закрыта наблюдением, не доказательством): доля заменяемых точек у случайных максимальных конфигураций A280537
  падает с размером (n = 7: 0.97, 0.89, 0.66, 0.35, 0.13 при |S| = 12…16), а доля пустых клеток с κ³ ≤ 2 — пуассоновский хвост
  e^{−λ}(1 + λ + λ²/2) при среднем λ конфигурации с точностью до 30 % (`~/saturation/slack/night_2026-09-02/vtora/kappa_poisson_log.txt`);
  у оптимумов λ ≈ 10.5–12.2 и ожидаемое число таких клеток < 1 при наблюдаемом 0. Всё это — измерения на случайных конфигурациях;
  доказанного утверждения нет.
- **вычисление, которому нужно общее утверждение:** сертификат жёсткости для больших свидетелей A280537 (n ≥ 12, |S| ≥ 31) без прямого
  счёта по всем клеткам: хотим из одних чисел |S|, n и «плотности плоскостей» знать, что хрупких клеток (κ³ ≤ 2) быть не может, и проверять
  лишь коллинеарные с парой клетки (второй механизм нежёсткости, conj-006d) — то есть довести отсечение lem-001 §граница до априорного.
- **чего не хватает (UNSPECIFIED):** детерминированное неравенство вида «если S ⊂ [n]³ максимально без четырёх компланарных и |S| = m,
  то число пустых клеток с κ³(q) ≤ 2 не больше f(n, m)» с явной f, обращающейся в 0 при m близком к a(n). Известно лишь тривиальное:
  Σ_q κ³(q) = Σ по тройкам S (число клеток решётки на плоскости тройки − 3), то есть средняя κ³ равна C(m,3)·(⟨клеток на плоскости⟩ − 3)/(n³ − m),
  а число клеток на плоскости через три точки решётки может быть и 3 (плоскость общего положения), так что нижняя оценка среднего через минимум
  пуста. Возможные пути: (а) считать не все плоскости, а «богатые» (координатные, диагональные) — у них ≥ n клеток и их доля среди троек
  оптимума измерима; (б) двойной счёт по прямым: клетка с κ³ ≤ 2 лежит не больше чем на двух плоскостях троек ⇒ ограничение на число точек S
  в каждом пучке плоскостей через q; (в) вероятностная модель максимальных конфигураций (нет — см. need-006: жадный рост не имеет
  замкнутой формы).
- **гипотеза (conj-007):** для максимальных S без четырёх компланарных при n ≤ 8 число клеток с κ³ ≤ 2 не превосходит
  (n³ − m)·e^{−λ}(1 + λ + λ²/2)·2, где λ — средняя κ³ той же конфигурации (пуассоновский хвост с запасом вдвое) — проверяемо на всех
  имеющихся популяциях (`rigid_kappa_dist_full.txt`, `kappa_poisson_log.txt`); ставка — при следующем измерении, числом в ledger.
- **кто возьмёт:** авторы сертификатов жёсткости/локальной оптимальности для A280537 при n ≥ 12; вычислительная геометрия решётки
  (богатые плоскости через тройки точек решётки — родня задаче о числе точек решётки на плоскости).
