# need-004 — комплекс коллинеарности (нить «новая алгебра», зажатая в нужду)

- **источник:** разговор с владельцем 3.09 о конвейере новых алгебр; ночь: жёсткость как утверждение о фасетах.
- **объект:** семейство множеств [n]² (или [n]³) без трёх на прямой замкнуто вниз ⇒ симплициальный комплекс Δ_n;
  максимальные грани — максимальные конфигурации; a(n) = dim Δ_n + 1; f-вектор — число законных множеств по размерам
  (`~/saturation/slack/night_2026-09-02/layers_n10.log` — слои дерева).
- **чего не хватает:** опознание: Δ_n — комплекс независимости 3-однородного гиперграфа коллинеарных троек; алгебра — кольцо
  Стенли–Райснера k[Δ_n]. Вопросы: чистый ли комплекс (нет: фасеты разных размеров — жадные тупики 2n−1), шеллабельность,
  коэн-маколеевость, h-вектор при малых n; связь A000755 со старшим коэффициентом f-вектора.
- **гипотеза (conj-004):** Δ_n не чистый при n ≥ 4 (фасеты размеров 2n и 2n−1 сосуществуют) — проверяется перебором при n=4…7;
  следствие: не шеллабелен в классическом смысле.
- **выход нити:** либо «известно как X, новых структур не нужно» + точные вопросы, либо новая структура — только через гейты 4–8.

- **шаг 1 (3.09, opus, перебор n = 2…5, Мак, < 1 с):** f-вектор Δ_n (число множеств без трёх на прямой по размерам) и фасеты:
  n=3: f = [1, 9, 36, 76, 78, 28, 2], фасеты по размерам {4: 5, 5: 16, 6: 2}; n=4: f = [1, 16, 120, 516, 1278, 1668, 998, 204, 11],
  фасеты {4: 2, 5: 8, 6: 210, 7: 116, 8: 11}; n=5: f = [1, 25, 300, 2148, 9498, 25052, 36698, 26700, 8242, 840, 32],
  фасеты {6: 152, 7: 1468, 8: 3474, 9: 520, 10: 32}. **conj-004 держится и усиливается: Δ_n не чистый уже при n = 3** (фасеты
  размеров 4, 5, 6), при n = 5 фасеты пяти размеров 6…10. Старший коэффициент f-вектора = A000755 (1, 2, 11, 32 ✓).
  Опознание: суммарные числа 2, 16, 230, 4812, 109536 (все множества без трёх на прямой) и числа фасет 1, 23, 347, 5646 в OEIS
  ОТСУТСТВУЮТ — кандидаты в новые последовательности (владелец решает). Δ_n — комплекс независимости 3-однородного гиперграфа
  коллинеарных троек; вопросы h-вектора/шеллабельности остаются; следующий шаг — n = 6, 7 на ВМ (счёт фасет по размерам) и
  формулировка «Δ_n не чистый при всех n ≥ 3» с доказательством (жадный тупик размера < a(n) строится явно).

- **шаг 2 (3.09, opus): n = 6 и опознание — нить закрыта как «известно + два кандидата в OEIS».** n=6 (26 с, Мак): f = [1, 36, 630, 6768,
  47331, 215448, 620210, 1073076, 1035097, 496436, 98950, 5664, 50], всего 3 599 697; фасеты {6: 8, 7: 172, 8: 11955, 9: 49332,
  10: 49830, 11: 5064, 12: 50} (50 = A000755(6) ✓). Минимальный размер фасеты 4, 4, 4, 6, 6 при n = 2…6 = **задача Гарднера о
  минимальном насыщенном множестве без трёх на прямой**: OEIS A277433 («all slopes version», как у нас: 1, 4, 4, 4, 6, 6, 8, 8, …) —
  с оговоркой, что при n ≤ 6 она совпадает с A219760 (только строки/столбцы/диагонали: 1, 4, 4, 4, 6, 6, 8, 9, …), и наши данные их
  не различают; литература: Cooper, Pikhurko, Schmitt, Warrington, «Martin Gardner's minimum no-3-in-a-line problem», Amer. Math.
  Monthly 121 (2014). Значит **нечистота Δ_n при n ≥ 3 — известный факт** (насыщенные множества меньше 2n), conj-004 закрыта опознанием.
  Не в OEIS: полные суммы f-вектора 2, 16, 230, 4812, 109536, 3599697 (число подмножеств n×n без трёх на прямой) и числа максимальных
  множеств 1, 1, 23, 347, 5646, 116411 — оформлены как кандидаты (`~/saturation/docs/oeis/collinearity_complex_candidates_2026-09-03.md`),
  решает владелец. Итог нити «новая алгебра»: Δ_n — комплекс независимости 3-однородного гиперграфа коллинеарных троек, k[Δ_n] — его
  кольцо Стенли–Райснера; новой структуры здесь нет, есть два незанятых числовых ряда и открытые вопросы (h-вектор, шеллабельность),
  которые без нужды не берём.
