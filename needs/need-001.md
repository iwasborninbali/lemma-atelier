# need-001 — жёсткость и радиус обмена: общая форма и граница

- **источник:** ночь 2→3.09, лемма 2 коллеги (`~/saturation/slack/night_2026-09-02/vtora/ЛЕММЫ.md`); использована для
  сертификатов «локальный оптимум радиуса ≥ r» на свидетелях 73, 94, 116, 138, 164 (`~/saturation/certs/no3_3d/`).
- **вычисление, которому нужно общее утверждение:** исчерпывающий обмен j точек на свидетелях куба стоит минуты только потому,
  что живые после удаления клетки — среди клеток с κ ≤ j. Хотим то же для «нет k+1 на прямой» и знать, где это ломается.
- **чего не хватает (UNSPECIFIED):** доказательство для общего k; граница — для запрета «нет 4 компланарных» (A280537) убийцы
  клетки q через точку p лежат в пучке плоскостей через pq, их много — лемма, по-видимому, ложна; нужен явный контрпример.
- **гипотеза (conj-001):** для множества S без k+1 точек на прямой и пустой клетки q: через любую p ∈ S проходит не больше
  k−1 «убивающих» наборов q ⇒ удаление j точек оживляет не больше чем на j·(k−1) по κ. Для плоскостей — ложно, контрпример при
  n ≤ 4 в A280537 (ставка: найдётся перебором за минуты).
