- **статус доказательства:** проверено машиной (доказательство ниже — четыре шага; точный перебор n = 3…6 дробями)
- **дальность (П / Б / О):** П — стоит: тождество с доказательством и перебором, опровергнуть нечего / Б — заменяет эвристику Гая–Келли
  точным средним для правильной нуль-модели (GK завышает в 1.4–2.9 раза при n ≤ 46) в любой работе, где сравнивают наблюдаемое число
  коллинеарных троек с ожиданием / О — тот же орбитный подсчёт даёт E[#плохих k-подмножеств] для любой инвариантной меры, а с меньшей

- **кто возьмёт:** всякий, кто оценивает «сколько коллинеарных троек ждать» у конфигурации с двумя точками в строке и столбце
  (Guy–Kelly 1968, Flammenkamp 1998) — формула вместо эвристики

## Формулировка (общая форма)

Пусть S — равномерно случайная конфигурация из ровно двух точек в каждой строке и каждом столбце решётки [n]² (таких конфигураций
A001499(n)), T(S) — число коллинеарных троек в S. Тогда

  E[T] = c(n) · τ(n) / (6 · C(n,3)²),   τ(n) = C(2n,3) − 4n² + 6n,   c(n) = A000938(n) − 2n · C(n,3),

где A000938(n) — число коллинеарных троек клеток решётки n×n (A000938(n) = 2 Σ_{k,m=2}^{n} (n−k+1)(n−m+1) gcd(k−1, m−1) − n²(n²−1)/6,
Larrosa Cañestro), c(n) — те из них, что не лежат в одной строке или столбце, τ(n) — число троек точек S в попарно разных строках и
столбцах (одно и то же у всех S), 6·C(n,3)² — число таких троек клеток во всей решётке.

Общая форма (орбитный подсчёт). Если μ — распределение случайного подмножества S ⊂ X, инвариантное относительно группы G, действующей на X,
и B — семейство «плохих» k-подмножеств X, то E[#{A ⊂ S : A ∈ B}] = Σ_O |O ∩ B| · E[N_O(S)] / |O| по G-орбитам O k-подмножеств X,
где N_O(S) = #{A ⊂ S : A ∈ O}. При G = S_n × S_n (перестановки строк и столбцов) и k = 3 орбит четыре: трансверсальные тройки; пара в
строке + третья; пара в столбце + третья; «угол» (пара в строке и пара в столбце); коллинеарные тройки лежат только в трансверсальной
орбите, и там N_O = τ(n) детерминировано.

## Доказательство

(1) Число троек точек S в попарно разных строках и столбцах. Из C(2n,3) вычитаем тройки с парой в одной строке (n строк, одна пара в
каждой, 2n − 2 третьих точек) и тройки с парой в одном столбце (столько же); тройки с парой в строке И парой в столбце вычтены дважды —
возвращаем. Такая тройка {a, b, c} имеет ровно одну клетку-«угол» b (a — партнёр b по строке, c — по столбцу): если бы угол был второй,
три точки лежали бы в одном столбце или строке. Углов 2n, значит τ = C(2n,3) − 2n(2n−2) + 2n = C(2n,3) − 4n² + 6n.

(2) Группа S_n × S_n переставляет конфигурации биективно, значит сохраняет равномерную меру; она транзитивна на трансверсальных тройках
клеток (три строки тройки переводятся в любые три строки, три столбца — в любые три столбца, а сопоставление строк столбцам внутри тройки
исправляется перестановкой столбцов). Поэтому p := Pr[A ⊂ S] одинаково для всех трансверсальных троек клеток A.

(3) Σ_A Pr[A ⊂ S] по всем трансверсальным A равна E[τ] = τ, а троек A ровно C(n,3)² · 3! = 6 C(n,3)². Отсюда p = τ / (6 C(n,3)²).

(4) Коллинеарная тройка точек S не лежит в строке или столбце (там ровно по две точки) — значит она трансверсальна. Коллинеарных
трансверсальных троек клеток c(n) = A000938(n) − 2n C(n,3) (в каждой из n строк и n столбцов ровно C(n,3) коллинеарных троек).
По линейности E[T] = c(n) · p. ∎

## Опознание

OEIS: A000938 (коллинеарные тройки решётки; формула Ларросы Каньестро 2010), A001499 (матрицы с двумя единицами в строке и столбце).
Guy & Kelly (1968) оценивают ожидаемое число коллинеарных троек у 2n случайных клеток без учёта строк и столбцов:
E_GK = A000938(n) · C(2n,3) / C(n²,3). Отношение E_GK / E[T] = 2.86, 2.20, 1.83, 1.86, 1.71, 1.65, 1.62, 1.57, 1.54, 1.48, 1.43 при
n = 3, 4, 5, 6, 8, 10, 12, 16, 20, 30, 46 — эвристика завышает среднее правильной нуль-модели в 1.4–2.9 раза. Явной формулы для E[T]
при фиксированных маргиналах в литературе по no-three-in-line не встречали (Flammenkamp 1998 использует эвристику GK); орбитный
подсчёт — стандартный приём (усреднение по группе). Вердикт: частично известно (метод), формула — не найдена; запрос в дип-ресерч 14.

## Граница

(а) Без фиксированных маргиналов (равномерные 2n-подмножества клеток) формула ложна: там E[T] = A000938(n) C(2n,3)/C(n²,3) = E_GK
(n = 4: 22/5 против 2 — `boundary_cases`). (б) Условие на НЕинвариантный признак меняет среднее: число точек в классе чётности
(нечётная, нечётная) при n = 4 даёт E[T | k] = 6, 9/4, 12/7, 9/4, 6 при k = 0…4 (`boundary_cases`); ночью при n = 20: 64.95 / 62.33 /
61.47 / 62.41 / 64.94 при k = 8…12. Это шаг 2 need-003: та же общая форма с группой, сохраняющей классы чётности строк и столбцов,
и орбитами троек по образцу чётностей. (в) Второй момент не слеп: дисперсия T зависит от типа циклов (граница lem-002).
