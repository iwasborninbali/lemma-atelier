  в строке и столбце; общий m) — точное число вместо приближения независимостью

## Формулировка (общая форма)

Определения. n ≥ 3. m-регулярная конфигурация — подмножество S ⊂ [n]² с ровно m точками в каждой строке и каждом столбце (m = 2 — случай
no-three-in-line; таких конфигураций A001499(n)). Тройка клеток **трансверсальна**, если её клетки лежат в попарно разных строках и попарно
разных столбцах. **Косая коллинеарная** тройка клеток — коллинеарная тройка не в одной строке и не в одном столбце; всякая косая коллинеарная
тройка трансверсальна (прямая ненулевого конечного наклона пересекает каждую строку и каждый столбец не более чем в одной клетке).
**Угол** тройки — клетка, образующая с одной из двух других пару в строке, а с другой — пару в столбце.

Утверждение. Пусть S равномерно распределена на m-регулярных конфигурациях, T(S) — число коллинеарных троек точек S. Тогда

  E[T] = c(n) · τ_m(n) / (6 · C(n,3)²) + 2n · C(m,3),

  c(n) = A000938(n) − 2n · C(n,3) — число косых коллинеарных троек клеток;
  τ_m(n) = C(mn,3) − n [C(m,3) + C(m,2)(mn − m)] − n [C(m,2)(mn − 3m + 2) + C(m,3)] — число трансверсальных троек точек у КАЖДОЙ
  m-регулярной конфигурации.

При m = 2: τ_2(n) = C(2n,3) − 4n² + 6n, осевой член равен нулю, E[T] = c(n) · τ_2(n) / (6 · C(n,3)²).
A000938(n) = 2 Σ_{k,m=2}^{n} (n−k+1)(n−m+1) gcd(k−1, m−1) − n²(n²−1)/6 (Larrosa Cañestro, OEIS A000938).

Общая форма — lem-002 v2 (рандомизационная лемма): для G = S_n × S_n и орбиты O троек клеток E[#{A ⊂ S : A ∈ B}] = |B ∩ O| · E[N_O(S)] / |O|,
суммируется по орбитам. Орбит троек клеток под S_n × S_n **шесть**: трансверсальные (6·C(n,3)²); три в строке (n·C(n,3)); три в столбце;
пара в строке + третья вне её строки и вне столбцов пары (n·C(n,2)(n−1)(n−2)); пара в столбце + третья; «угол» (n²(n−1)²).
Коллинеарные тройки клеток лежат в трёх орбитах: косые — в трансверсальной, остальные — «три в строке» и «три в столбце»; в орбитах с
парой и свободной третьей клеткой и в орбите «угол» коллинеарных троек нет (прямая через пару горизонтальна или вертикальна, третья
клетка вне её — у угла тоже: она в другой строке и другом столбце пары).

## Доказательство

(1) τ_m: тройка точек S содержит не более одной пары в строке и не более одной пары в столбце (две строчные пары в тройке дали бы три
точки в строке, что при подсчёте учтено отдельно как «три в строке»). Из C(mn,3) вычитаем тройки с ≥ 2 точками в одной строке: три в
строке — n·C(m,3); ровно пара в строке и третья вне этой строки — n·C(m,2)(mn − m). Затем тройки с ≥ 2 точками в одном столбце, ещё не
вычтенные: три в столбце — n·C(m,3); пара в столбце с третьей вне столбца И вне строк обеих точек пары (иначе тройка уже вычтена как
«пара в строке» — это тройки с углом) — n·C(m,2)(mn − m − 2(m − 1)) = n·C(m,2)(mn − 3m + 2). Итого τ_m(n) как в формулировке; тройки с
углом посчитаны ровно один раз, потому что угол у тройки единственный: он есть пересечение единственной строчной и единственной столбцовой
пары. При m = 2 (C(2,2) = 1, C(2,3) = 0): C(2n,3) − n(2n−2) − n(2n−4) = C(2n,3) − 4n² + 6n.

(2) Группа S_n × S_n переставляет m-регулярные конфигурации биективно и потому сохраняет равномерную меру. Она транзитивна на
трансверсальных тройках клеток при n ≥ 3: тройка задаёт биекцию своих трёх строк на свои три столбца; перестановка строк σ совмещает строки
двух троек, перестановка столбцов π совмещает образы под этими биекциями; при n ≥ 3 обе продолжаются до перестановок. Значит
p := Pr[A ⊂ S] одинаково для всех трансверсальных троек клеток A.

(3) Σ_A Pr[A ⊂ S] по трансверсальным A = E[число трансверсальных троек в S] = τ_m(n) по (1); троек A ровно 6·C(n,3)². Отсюда
p = τ_m(n) / (6·C(n,3)²).

(4) Коллинеарная тройка точек S с двумя точками в одной строке лежит на горизонтальной прямой, значит все три её точки — в этой строке
(аналогично для столбцов). Поэтому T = (косые коллинеарные тройки в S) + (тройки в строках) + (тройки в столбцах). Косых коллинеарных
троек клеток c(n), каждая трансверсальна, каждая лежит в S с вероятностью p: вклад c(n)·p. В каждой строке ровно m точек, все на одной
прямой: ровно C(m,3) троек, детерминировано; столбцы так же: вклад 2n·C(m,3). По линейности E[T] = c(n)·p + 2n·C(m,3). ∎

## Опознание

Общая форма — рандомизационная лемма (Hoeffding 1952, Ann. Math. Statist. 23; Lehmann & Romano, Testing Statistical Hypotheses, гл. 15):
условно на орбите данных под конечной группой закон равномерен; lem-002 v2 этого репозитория выводит из неё E[N_B | 𝒜] = (|B|/|O|)·E[N_O | 𝒜]
и в §Частный случай уже выписывает формулу для m = 2 (154/25 при n = 6, 22 974/361 при n = 20). lem-004 — случай F ≡ const той же формулы;
своё здесь — замкнутая форма c(n) через A000938, подсчёт τ_m и осевой член для m ≥ 3. OEIS: A000938, A001499.
Гай–Келли (Guy, Kelly, Canad. Math. Bull. 11 (1968) 527–531) — вероятностная эвристика для асимптотики максимума ≈ c·n: в статье
3c³ = 2π² ⇒ c ≈ 1.874; Gabor Ellmann (2004) указал на ошибку подстановки, исправление 3c² = π² ⇒ c = π/√3 ≈ 1.8138 (комментарии OEIS
A000769; в репозитории — `~/saturation/paper/guy_kelly_error.tex`, `docs/research/deep_research_brief_5_barrier.md`; ночной вывод через
6/π² даёт то же π/√3). Какую именно нуль-модель они используют для среднего числа троек (2n клеток равномерно, с повторениями или иначе) —
**UNSPECIFIED** до чтения первоисточника; поправка lem-004 (3/n) на константу не влияет. Формула
E_наивн = A000938(n)·C(2n,3)/C(n²,3) ниже — НАША модель «2n клеток равномерно» (`naive_uniform` в коде), не их.

## Граница

(а) Равномерные 2n-подмножества клеток (без фиксированных маргиналов): E[T] = A000938(n)·C(2n,3)/C(n²,3) (n = 4: 22/5 против 2). Разложение
E_наивн/E[T] = (A000938/c)·(C(2n,3)/τ_2)·(6C(n,3)²/C(n²,3)) показывает, что первый множитель (осевые тройки) больше всего разрыва: без осевых
троек наивная модель занижает — c(n)·C(2n,3)/C(n²,3) ÷ E[T] = 0.600, 0.660, 0.761, 0.866, 0.938, 0.971, 0.990 при n = 4, 6, 10, 20, 46, 100, 300.
(б) Условие на НЕинвариантный признак меняет среднее: число точек в классе чётности (нечётная, нечётная) при n = 4 даёт E[T | k] = 6, 9/4,
12/7, 9/4, 6 при k = 0…4; ночью при n = 20: 64.95 / 62.33 / 61.47 / 62.41 / 64.94 при k = 8…12 — шаг 2 need-003 (меньшая группа, орбиты
троек по образцу чётностей). (в) Второй момент не слеп (lem-002 v2: Var[T | тип] = 16.95 / 12.97 / 10.99 / 10.92 при n = 6).
(г) Неинвариантная мера или недетерминированный N_O ломают общую форму (lem-002, противник №1).

## Носители

Инструмент, один носитель: no-three-in-line и m-регулярные таблицы (нуль-модели с фиксированными маргиналами — переформулировка, не применение).
Для статистика (форма противника №1): в нуль-модели с фиксированными маргиналами вероятность занятости заданного трансверсального паттерна
одинакова для всех таких паттернов и известна точно — детерминированное число паттернов, делённое на размер орбиты, — поэтому среднее
U-статистики считается точно, без приближения независимостью.
