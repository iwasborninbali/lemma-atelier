## ПРОТИВ ФОРМЫ

**1. Раздел «Опознание» заполнен ложным предложением — правка №6 сделана по форме.** Написано: «Линк вершины q в (k+1)-однородном гиперграфе коллинеарных наборов линейного пространства — паросочетание (λ ≤ 1 на парах вершин)». Оба свойства приписаны одному объекту, а принадлежат двум разным. У гиперграфа рёбер-«коллинеарных (k+1)-наборов» пара точек лежит в C(m−2,k−1) рёбрах своей прямой, то есть λ > 1; а линк q — дизъюнктное объединение полных графов на ℓ∖{q} по прямым ℓ ∋ q (в Z², k=2, строка через q даёт {a,b} и {b,c} — общая b), то есть НЕ паросочетание. λ ≤ 1 верно для гиперграфа блоков-прямых, паросочетание возникает только после пересечения со **S, независимым** (в нём нет полного ребра) — ровно предпосылка леммы, в предложении отсутствующая. №1 писал осторожнее («частичное паросочетание»); v2 при переписывании потеряла хедж и получила неверное утверждение. Форма для другого сейчас не работает: человек из теории дизайнов возьмёт неверную фразу. Рабочая: «в частичной штейнеровской системе (любые две точки — не больше чем в одном блоке) для независимого S и q ∉ S блоки через q пересекают S по попарно дизъюнктным множествам, ибо два блока делят только q».
