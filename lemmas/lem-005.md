## Формулировка (общая форма)

Пусть конечное множество клеток X разбито на прямые ℓ_1, …, ℓ_r направления v (каждая клетка ровно на одной прямой), |ℓ_i| = L_i.
Пусть S — равномерно случайное m-подмножество X среди тех, у которых |S ∩ ℓ_i| ≤ 2 для всех i. Тогда

  Z_m := #{допустимых S} = [t^m] ∏_{i=1}^{r} (1 + L_i t + C(L_i, 2) t²),

  E[#{i : |S ∩ ℓ_i| = 2}] = (1/Z_m) · Σ_{i=1}^{r} C(L_i, 2) · [t^{m−2}] ∏_{j ≠ i} (1 + L_j t + C(L_j, 2) t²).

Применение (модель прямых для no-three-in-line). Для решётки [n]², направления v и m = 2n положим E_v := E[#дважды занятых прямых
направления v] по формуле выше (в решении задачи всякая прямая несёт ≤ 2 точки, и число пар примитивного направления v равно числу
дважды занятых прямых направления v). Одна перенормировка на точное число трансверсальных пар решения 2n² − 3n: Z_n := (2n² − 3n) /
Σ_{v ≠ осевые} E_v, и модельный спектр c_v^{модель} := Z_n · E_v / n (среднее по ориентациям класса).

## Доказательство

Множество S допустимо ⟺ на каждой прямой выбрано 0, 1 или 2 клетки; выбор на прямой ℓ_i из x_i клеток делается C(L_i, x_i) способами
при x_i ∈ {0, 1, 2}, и выборы на разных прямых независимы (прямые — разбиение X). Значит число допустимых S с Σ x_i = m — коэффициент при
t^m в произведении ∏(1 + L_i t + C(L_i, 2) t²). Далее E[#дважды занятых] = Σ_i P(x_i = 2), а число допустимых S с x_i = 2 равно
C(L_i, 2) · [t^{m−2}] ∏_{j≠i}(…): выбрать две клетки на ℓ_i и m − 2 клеток на остальных прямых допустимо. ∎

## Опознание

Тождество — элементарная производящая функция «шары по ящикам ёмкости 2 с весами C(L, x)» (учебный уровень; частный случай
многочлена паросочетаний/ладейного многочлена для дизъюнктных блоков). Своё — применение: спектр направлений решений no-three-in-line
как функция длин прямых при единственном ограничении «≤ 2 на прямой» с одной перенормировкой; прайор-арт по спектру направлений —
бриф 14 (не запускался). UNSPECIFIED: известна ли такая модель в литературе по no-three-in-line (Guy–Kelly, Flammenkamp 1992/1998).

## Граница

(а) Без перенормировки модель ниже базы на 13–26 % (n = 20): она не знает, что число пар фиксировано. (б) Модель не даёт
константности по n (дрейф 3–8 % между n = 20 и 40), тогда как база даёт константы в 1 % — значит, «константа по n» не выводится
из этой модели и остаётся измерением. (в) Систематика: после перенормировки модель ниже базы на 3–10 % во всех направлениях,
кроме (1,1) (+4.5 %) и (1,2) (0 %) — маргиналы строк/столбцов не учтены (веса C(L, x) равновесны по клеткам). (г) Парная модель первого
порядка (независимое исключение вдоль прямой) — ложная альтернатива: переистощает короткие направления вдвое и путает порядок.

## Носители

1. no-three-in-line: абсолютный спектр направлений, включая κ (инструмент + первое предсказание, проверенное вслепую).
