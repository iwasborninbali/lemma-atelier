## Формулировка (общая форма)

Пусть конечное множество клеток X разбито на прямые ℓ_1, …, ℓ_r направления v — классы отношения «лежат на одной прямой направления v»;
клетки без соседа в направлении v образуют прямые длины 1 (они входят в разбиение и дают множители 1 + t); |ℓ_i| = L_i. Пусть
2 ≤ m ≤ Σ_i min(L_i, 2) (тогда Z_m > 0), и S — равномерно случайное m-подмножество X среди тех, у которых |S ∩ ℓ_i| ≤ 2 для всех i
(«допустимость относительно v» — ограничение только на прямых направления v; такое S не обязано быть решением задачи). Тогда

  Z_m := #{допустимых S} = [t^m] ∏_{i=1}^{r} (1 + L_i t + C(L_i, 2) t²),

  E[#{i : |S ∩ ℓ_i| = 2}] = (1/Z_m) · Σ_{i=1}^{r} C(L_i, 2) · [t^{m−2}] ∏_{j ≠ i} (1 + L_j t + C(L_j, 2) t²).

Применение (модель прямых для no-three-in-line). Для решётки [n]², направления v и m = 2n положим E_v := E[#дважды занятых прямых
направления v] по формуле выше (в 2n-точечном решении всякая прямая несёт ≤ 2 точки, и число пар примитивного направления v равно числу
дважды занятых прямых направления v). У решения ровно 2n осевых пар (по одной в каждой строке и каждом столбце), поэтому число
неосевых («трансверсальных») пар равно C(2n, 2) − 2n = 2n² − 3n — точное тождество задачи. Осевые направления исключаются: там
ограничение «≤ 2» выполнено тождественно (E = n, информации нет) и их пары уже вычтены. Одна перенормировка: Z_n := (2n² − 3n) /
Σ_{v неосевые примитивные} E_v; модельный спектр c_v^{модель} := Z_n · E_v / n (среднее по ориентациям класса). Замечание: модель
сама даёт Σ_v E_v = 615.3 при n = 20 против 740 (−17 %) — масштаб навязан, форма (отношения) выведена.

## Доказательство

Множество S допустимо ⟺ на каждой прямой выбрано 0, 1 или 2 клетки; выбор на прямой ℓ_i из x_i клеток делается C(L_i, x_i) способами
при x_i ∈ {0, 1, 2}, и выборы на разных прямых независимы (прямые — разбиение X). Значит число допустимых S с Σ x_i = m — коэффициент при
t^m в произведении ∏(1 + L_i t + C(L_i, 2) t²). Далее E[#дважды занятых] = Σ_i P(x_i = 2), а число допустимых S с x_i = 2 равно
C(L_i, 2) · [t^{m−2}] ∏_{j≠i}(…): выбрать две клетки на ℓ_i и m − 2 клеток на остальных прямых допустимо. ∎

## Опознание

Тождество — элементарная производящая функция: канонический ансамбль жёстких частиц на r независимых ящиках вместимости 2 с
вырождениями 1, L, C(L,2) (решёточный газ с исключением), он же ладейный многочлен дизъюнктных блоков, он же условное распределение
равномерного размещения при обусловливании «≤ 2 в ящике» (противник №1). Эвристика Гая–Келли 1968 — тоже сумма по примитивным
направлениям, но троек в равномерной модели, не пар при «≤ 2»; опубликованного спектра направлений реальных решений противник поиском не
нашёл — бриф 14 обязателен. Своё — применение: спектр направлений решений no-three-in-line
как функция длин прямых при единственном ограничении «≤ 2 на прямой» с одной перенормировкой; прайор-арт по спектру направлений —
бриф 14 (не запускался). UNSPECIFIED: известна ли такая модель в литературе по no-three-in-line (Guy–Kelly, Flammenkamp 1992/1998).

## Граница

(а) Без перенормировки модель ниже базы на 13–26 % (n = 20): она не знает, что число пар фиксировано. (б) «База константна по n, модель дрейфует» — ЛОЖНО (противник №1, прогон скрипта коллеги по стратам базы): константны только
короткие направления ((1,1): 0.7308 / 0.7327 / 0.7325 при n = 19–20 / 29–31 / 32–57), длинные растут с n ((1,7): 0.2071 / 0.2340 / 0.2461;
(3,7): 0.1791 / 0.2069 / 0.2209, +23 %); «константы базы» — усреднение по смеси n, где выше n = 20 есть только симметричные решения
(n и симметрия неразделимы по построению базы). Честное сравнение — модель(n) с базой(n): при n = 20 (1,7) 0.1931 / 0.2071 = 0.932 и
(3,7) 0.1669 / 0.1791 = 0.932 вместо 0.865 / 0.851 против смеси. Слепая ставка выиграна (предсказания до измерения), но её сравнение
шло при несогласованном n — оговорка. (в) Систематика после перенормировки — не артефакт и не «маргиналы»: Z навязывает
Σ_v c_v = 2n − 3 точно, поэтому дефицит головы (пятнадцать классов: модель 17.12 против базы 18.59, −1.47 из 37) ровно равен избытку
хвоста редких крутых направлений; второй перенормировкой это не лечится; маргиналы строк/столбцов объясняют не больше трети (свободное
2n-подмножество даёт 705.7 трансверсальных пар против 740, модель — 615.3: пересжатие от условия «≤ 2» в ОДНОМ направлении, тогда как
реальная конфигурация давится всеми направлениями сразу). (г) Парная модель первого
порядка (независимое исключение вдоль прямой) — ложная альтернатива: переистощает короткие направления вдвое и путает порядок.
