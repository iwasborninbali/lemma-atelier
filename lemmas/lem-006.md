## Формулировка (общая форма)

p — нечётное простое, h = (p−1)/2, c ∈ F_p^*, H_c = {(x, y) ∈ ℤ² : xy ≡ c (mod p)}, окно HJSW G_p = {−h, …, 3h+1} × {0, …, 2p−1},
P = H_c ∩ G_p (|P| = 4(p−1): каждый из p−1 классов κ = (a, b), ab = c, имеет в окне ровно четыре точки — вершины квадрата со стороной p).
Множество законно, если нет трёх коллинеарных точек; прямая богата, если несёт ≥ 3 точек P; L — множество богатых прямых, Z — число точек P
вне богатых прямых; s = [c — КВ] + [−c — КВ] ∈ {0, 1, 2}. На классах действует группа Клейна V = {1, σ, τ, ν}: σ(a, b) = (−b, −a), τ(a, b) = (b, a),
ν = στ; орбита общая (четыре класса) или исключительная (два класса {κ, νκ}, оба фиксированы σ или оба τ; таких орбит ровно s). Пары партнёров
класса κ — {κ, σκ} (σ-пара) и {κ, τκ} (τ-пара).

**Теорема (main).** (i) Всякая богатая прямая имеет наклон ±1; их ровно 3(p−1)/2 − s: p−1 с тремя точками и (p−1)/2 − s с четырьмя; Z = 2s.
(ii) Всякое законное S ⊂ P имеет ≤ 3(p−1) точек, граница достигается; ЛП-релаксация (Σ x_q → max при Σ_{q∈ℓ} x_q ≤ 2 по ℓ ∈ L, 0 ≤ x_q ≤ 1) имеет
оптимум 3(p−1) — утверждение об оптимуме, не о целочисленности многогранника. (iii) Число законных подмножеств размера 3(p−1) равно 9^s;
все они совпадают с множеством HJSW вне (не более четырёх) классов (a, ±a) с a² = ±c.

**Теорема (window).** Пусть W = [x₀, x₀+2p) × [y₀, y₀+2p), ρ_x(a) ∈ [x₀, x₀+p), ρ_y(b) ∈ [y₀, y₀+p) — представители вычетов, d_κ = ρ_x(a) − ρ_y(b),
e_κ = ρ_x(a) + ρ_y(b). σ-пара {κ, σκ} общая, если d_σκ = d_κ (её четыре копии на одной диагонали), и расщеплённая иначе (d_σκ − d_κ = ±p: две
трёхточечные диагонали); τ-пара — так же по e. Для общей орбиты (e_O, f_O) — числа расщеплённых σ- и τ-пар; орбитная лемма: (e_O, f_O) ∈
{(0,0), (0,2), (1,1), (2,0)}. Пусть n₂, n₁, n₀ — числа общих орбит с образцами {(0,2),(2,0)}, (1,1), (0,0); n₂ + n₁ + n₀ = (p−1−2s)/4; s₁ (s₂) — число
исключительных орбит, чья пара расщеплена (общая), s₁ + s₂ = s. Тогда максимум законного подмножества H_c ∩ W равен

  12n₂ + 10n₁ + 8n₀ + 6s ≤ 12(n₂ + n₁ + n₀) + 6s = 3(p−1),

с равенством ⟺ n₁ = n₀ = 0, а число максимумов равно 144^{n₁}·1296^{n₀}·9^{s₁}·6^{s₂}. Окно HJSW: n₂ = (p−1−2s)/4, s₁ = s.

## Доказательство

В заметке (§Rich lines, §Proof): по лемме Лагранжа прямая через две точки H_c встречает ≤ 2 классов (квадратичная конгруэнция по параметру
прямой); четыре копии класса — квадрат со стороной p, значит богатая прямая имеет наклон ±1 и лежит в одной V-орбите; двойной счёт
|S| ≤ Z + 2|L| и тождество Z + 2|L| = 3(p−1) (|L| = 3(p−1)/2 − s, Z = 2s). Равенство ⟺ (I) все Z точек вне богатых прямых взяты, (II) ровно две
точки S на каждой богатой прямой, (III) **ни одна точка S** не лежит на двух богатых прямых (на двух богатых прямых лежат p−1−2s средних копий
класса — они в максимум не входят). По орбитам: общая орбита даёт ровно один выбор, исключительная — 9. Для окна — орбитная лемма (окно
расщепляет 0 или 2 пары каждой общей орбиты) и максимумы гаджетов 8, 10, 12, 12 с кратностями 1296, 144, 1, 1.

## Опознание

Заметка (tex:56, 114–118) сама разделяет: значение 3(p−1) и качественная оптимальность S₂, S₃ утверждались Kovács–Nagy–Szabó 2025 (App. A;
их общая оценка |R| ≥ X/2 даёт 3(p−1) + s), **новы — само доказательство**, критерий единственности (p ≡ 1 mod 4 и c — неквадрат), точное
значение и число максимумов для каждого окна 2p×2p, значение и число для запрета «четыре на прямой». Площадки поиска: заметка ссылается на
Shparlinski (обзор модулярных гипербол), KMSW, FKNN17 (NP-трудность общего положения), PW13; App. A KNS25 в ателье никем не читана.
Вердикт: **частично известно** (значение и оптимальность — KNS25), доказательство и классификация — новое по заметке.

## Граница

1. Составной модуль (m = 9, окно 2m×2m): лемма Лагранжа не работает, богатые прямые наклонов −1, 1/2, 1, 2 (`boundary_cases`; тест коллеги
   проверяет лишь «не ⊆ {±1}»).
2. Окно шире 2p (2p+1 столбцов, p = 5): максимум 13 > 12 = 3(p−1) — размер окна существенен; для бо́льших окон заметка даёт только MIP-таблицу.
3. Две гиперболы H(1) ∪ H(−1) в окне HJSW (p = 5): максимум 14 > 12 — теорема об одной гиперболе не переносится; оценка заметки
   ≤ 4(p−1) − 4m₈(p) с m₈ > 0 доказана для 19 ≤ p ≤ 1500 (и m₈ = (1/12 + o(1))p), p = 5 — вне её области; далее (3.4482 + o(1))(p−1) — need-009.
4. Пропущенная строка в доказательстве орбитной леммы (случай k = 0: «F₁ ⟹ v ≥ 1», tex:564–566) — находка противника №1, по существу
   восполнима; передать автору заметки.
