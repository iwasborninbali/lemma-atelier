## Формулировка (общая форма)

p — нечётное простое, h = (p−1)/2, c ∈ F_p^*, H_c = {(x, y) ∈ ℤ² : xy ≡ c (mod p)}, окно HJSW G_p = {−h, …, 3h+1} × {0, …, 2p−1},
P = H_c ∩ G_p (|P| = 4(p−1): каждый из p−1 классов (a, b), ab = c, имеет в окне ровно четыре точки — вершины квадрата со стороной p).
Множество законно, если нет трёх коллинеарных точек; прямая богата, если несёт ≥ 3 точек P; s = [c — КВ] + [−c — КВ] ∈ {0, 1, 2}.

**Теорема (main).** (i) Всякая богатая прямая имеет наклон ±1; их ровно 3(p−1)/2 − s: p−1 с тремя точками и (p−1)/2 − s с четырьмя; ровно 2s
точек P не лежат ни на одной богатой прямой. (ii) Всякое законное S ⊂ P имеет ≤ 3(p−1) точек, граница достигается; ЛП-релаксация
(Σ x_q → max при Σ_{q∈ℓ} x_q ≤ 2 по богатым ℓ, 0 ≤ x_q ≤ 1) имеет оптимум 3(p−1). (iii) Число законных подмножеств размера 3(p−1) равно 9^s;
все они совпадают с множеством HJSW вне (не более четырёх) классов (a, ±a) с a² = ±c.

**Теорема (window).** Для любого окна W = [x₀, x₀+2p) × [y₀, y₀+2p) максимум законного подмножества H_c ∩ W равен 12n₂ + 10n₁ + 8n₀ + 6s ≤ 3(p−1),
где n₂, n₁, n₀ — числа общих орбит группы Клейна, у которых окно расщепляет пары партнёров по образцам {(0,2),(2,0)}, (1,1), (0,0).

## Доказательство

В заметке (§Rich lines, §Proof): по лемме Лагранжа прямая через две точки H_c встречает ≤ 2 классов; четыре копии класса — квадрат со
стороной p, значит богатая прямая имеет наклон ±1 и лежит в одной орбите группы Клейна V = {1, σ, τ, ν}; двойной счёт |S| ≤ Z + 2|L| и
тождество Z + 2|L| = 3(p−1); равенство ⟺ (I) все Z точек вне богатых прямых взяты, (II) ровно две на каждой богатой прямой, (III) нет точки
на двух богатых прямых — по орбитам: общая орбита даёт один выбор, исключительная — 9. Для окна — орбитная лемма (окно расщепляет 0 или 2
пары каждой общей орбиты) и максимумы гаджетов 8, 10, 12, 12.

## Опознание

Kovács–Nagy–Szabó 2025 утверждают качественную оптимальность S₂ (и общая оценка |R| ≥ X/2 даёт 3(p−1) + s); точное значение, 9^s, ЛП и
классификация — новое в заметке (§Introduction). Метод — стандартный двойной счёт по богатым прямым + орбитная структура.

## Граница

1. Составной модуль (m = 9, окно 2m×2m): лемма Лагранжа не работает, богатые прямые наклонов −1, 1/2, 1, 2 (`boundary_cases`).
2. Окно шире 2p (2p+1 столбцов, p = 5): максимум 13 > 12 = 3(p−1) — граница окна существенна.
3. Две гиперболы H(1) ∪ H(−1) в окне HJSW (p = 5): максимум 14 > 12 — теорема об одной гиперболе не переносится; статья даёт
   ≤ (11/3 + o(1))(p−1) и далее (3.4482 + o(1))(p−1) — это need-009.

## Носители

Инструмент для need-009 (приложение «конструкции по гиперболам не достигают 2n»): одна гипербола — ровно барьер 3/2 (в единицах 2p, с
точностью до −3); две — < 11/6; честно: объединения многих гипербол и другие кривые (кроме кубик и коник) не покрыты.
