## Формулировка (общая форма)

**Предпосылки.** X — множество клеток; μ — распределение случайного подмножества S ⊂ X; G — группа, действующая на X так, что μ
G-инвариантна (μ(gS ∈ W) = μ(S ∈ W) для измеримых W); k-подмножества X разбиты на G-орбиты, и рассматриваемая орбита O **конечна** —
это единственное условие конечности: ни конечность G, ни конечность орбиты самой конфигурации S, ни счётность числа орбит не нужны
(доказательство ниже — прямой счёт по A ∈ O, без орбитной σ-алгебры; противник №2). Для подмножества S и семейства C k-подмножеств пишем
N_C(S) := #{A ⊂ S : A ∈ C} (для C ⊂ O это число ≤ |O| < ∞). 𝒜 — G-инвариантная σ-алгебра событий (W ∈ 𝒜 ⇒ gW = W; порождена
инвариантными признаками F: F(gS) = F(S)); условные средние по событию F = f берутся при μ(F = f) > 0.

**Лемма (следствие рандомизационной леммы).** Для любого B ⊂ O

  E[N_B(S) | 𝒜] = (|B| / |O|) · E[N_O(S) | 𝒜]   почти наверное.

**Следствие (детерминированный счёт).** Если N_O(S) = N_O — одна константа на носителе μ, то E[N_B | F = f] = |B|·N_O/|O| для всякого
инвариантного F и всякого f с μ(F = f) > 0 — не зависит от f. Эквивалентная нарушаемая форма: **Cov(N_B, F) = 0 для каждой инвариантной
вещественной F** (нарушение — любая инвариантная F с ненулевой ковариацией). Чтобы проверить это при n = 6 конечным перебором, нужна строка:
**орбиты S_n × S_n на 2-регулярных конфигурациях — это ровно типы циклов** (граф строки–столбцы конфигурации — дизъюнктное объединение
чётных циклов; две конфигурации с одним типом циклов изоморфны как двудольные графы с сохранением долей, а такой изоморфизм и есть пара
перестановок строк и столбцов). Поэтому всякая инвариантная F — функция типа циклов, и равенство четырёх условных средних при n = 6 даёт
Cov(T, F) = 0 для всех инвариантных F сразу.

**Частный случай (плоскость, лемма 1 ночи).** X = [n]², μ равномерна на конфигурациях с ровно двумя точками в каждой строке и каждом
столбце (их A001499(n)), G = S_n × S_n (перестановки строк и столбцов), O — трансверсальные тройки клеток (попарно разные строки и
столбцы) — одна орбита, |O| = C(n,3)² · 3! = 6·C(n,3)². B := **косые коллинеарные тройки клеток** (коллинеарные и трансверсальные; B ⊂ O
по определению), |B| = A000938(n) − 2n·C(n,3). Отдельный шаг: **тройка точек S коллинеарна только на косой прямой** — строка и столбец несут
ровно по две точки, поэтому строчные и столбцовые коллинеарные тройки клеток (они в O не лежат) никогда не заполнены, и число T(S)
коллинеарных троек точек равно N_B(S). Счёт N_O(S) детерминирован: N_O = τ(n) = C(2n,3) − 4n² + 6n. Итог: для всякого инвариантного F
(тип циклов 2-фактора, число прямоугольников, любой признак графа строки–столбцы)

  E[T | F = f] = |B|·τ(n)/(6·C(n,3)²),   и число предъявлено до счёта: n = 6: 132·112/2400 = **154/25 = 6.16**; n = 20: 59 076·8400/7 797 600 =
  **22 974/361 ≈ 63.64** (|O| = 2400 и 7 797 600; |B| = N₃(6) = 132, N₃(20) = 59 076 — независимо пересчитано противником №1 через Σ φ(d)·A_d²).

## Доказательство

Прямой счёт (форма v1, возвращена по требованию противника №2 — не требует ни конечности орбиты S, ни счётности числа орбит). Пусть
W ∈ 𝒜 (gW = W для всех g) и A, A′ ∈ O, A′ = gA. Тогда 1{A′ ⊂ S} = 1{A ⊂ g⁻¹S}, и по инвариантности μ и W:
μ(A′ ⊂ S, S ∈ W) = μ(A ⊂ g⁻¹S, g⁻¹S ∈ W) = μ(A ⊂ S, S ∈ W). Значит c_W := μ(A ⊂ S, S ∈ W) одна и та же для всех A ∈ O. Суммируя
по конечной O: E[N_O · 1_W] = |O|·c_W, а по B ⊂ O: E[N_B · 1_W] = |B|·c_W. Итак E[N_B · 1_W] = (|B|/|O|)·E[N_O · 1_W] для всякого W ∈ 𝒜,
что и есть E[N_B | 𝒜] = (|B|/|O|)·E[N_O | 𝒜] почти наверное (обе величины ограничены, условные средние существуют). ∎
Связь с рандомизационной леммой (Hoeffding 1952; Lehmann–Romano, гл. 15: при конечной группе условно на орбите данных закон равномерен):
когда образ G в Sym(X) конечен, тот же вывод получается усреднением по орбите S и башней; наш прямой счёт обходится без этого.
Следствие: при N_O ≡ N_O константе правая часть равна |B|·N_O/|O| — константа, не зависящая от f; ковариация с любой инвариантной F
нулевая, потому что E[N_B | F] постоянна. Строка про орбиты 2-регулярных конфигураций — выше, в формулировке. ∎
Частный случай, детерминированность τ(n): из C(2n,3) троек точек вычитаем тройки с парой в одной строке (n пар, по 2n − 2 третьих точек) и
с парой в одном столбце (столько же); тройки с строчной И столбцовой парой вычтены дважды — их ровно 2n (у такой тройки один «угол»);
τ = C(2n,3) − 2n(2n − 2) + 2n = C(2n,3) − 4n² + 6n. Строчная/столбцовая тройка точек невозможна (ровно две точки в строке и столбце) —
коллинеарные тройки точек все косые, T = N_B. ∎

## Опознание

Общая форма — **учебный факт**: рандомизационная лемма / randomization principle (W. Hoeffding, «The large-sample power of tests based on
permutations of observations», Ann. Math. Statist. 23 (1952), 169–192; E. L. Lehmann, J. P. Romano, *Testing Statistical Hypotheses*, 3-е изд.,
Springer, 2005, гл. 15: условно на орбите данных под конечной группой закон равномерен), плюс линейность математического ожидания; наш
прямой счёт по одной конечной орбите паттернов — та же идея без конечности группы. Рядом: инвариантная σ-алгебра и E[f(gS) | ℐ] =
E[f(S) | ℐ]; усреднение по конечной группе (оператор Рейнольдса); принцип массопереноса для транзитивных действий. Отличие леммы на общем
уровне — **нулевое**; своё — (а) N_O = τ(n) для 2-регулярных конфигураций и (б) вывод для no-three-in-line: типы циклов и число
прямоугольников не входят ни в какое предсказание типа Гая–Келли. Поэтому статус — **следствие**, не лемма ателье. Форма для статистика:
U-статистика, ядро которой постоянно на одной орбите паттернов, имеет одно и то же условное среднее при любом инвариантном признаке.

## Граница

1. **Инвариантность μ неустранима** (противник №1): X = {1,2,3}, G = Z/3, k = 1, O = X, N_O ≡ 1, F ≡ const; μ({1}) = μ({2}) = 1/2 даёт
   E[1{1 ∈ S}] = 1/2 ≠ 1/3 (`noninvariant_measure_witness`).
2. **Детерминированность N_O — предпосылка следствия, не леммы:** X та же, μ: ∅ с 1/2, каждое {i} с 1/6 (инвариантна), F = |S|:
   E[1{1 ∈ S} | |S| = 0] = 0 ≠ 1/3 — следствие ложно, лемма верна (правая часть E[N_O | 𝒜] = 0). Куб A399138 (запрет «три на прямой»):
   G = S_n × S_n × S_n — независимые перестановки значений трёх координат, μ — любая G-инвариантная мера (например, равномерная на
   m-подмножествах [n]³), F — инвариантный признак (мультимножества профилей слоёв по каждой оси). Коллинеарные тройки клеток лежат в
   **семи** G-орбитах троек: осевые (меняется одна координата) ×3, диагонали граней (две координаты) ×3, пространственные (все три); ни в одной
   счёт N_O(S) не детерминирован. Поэтому первым моментом виден не «ровно E[N_O | F]», а сумма по орбитам
   E[T | F] = Σ_O (|B ∩ O|/|O|)·E[N_O | F] — форма lem-004 коллеги; больше первый момент из профиля не извлекает.
   На плоскости при нефиксированных маргиналах (`boundary_case`, n = 4): E[косых коллинеарных | профиль строк] зависит от профиля, а
   пропорция E[N_B | 𝒜]·|O| = |B|·E[N_O | 𝒜] держится в каждом классе (`boundary_case.ratio_ok`, под assert в тесте коллеги и в `__main__`).
3. **Признак должен быть инвариантен:** расстояния между точками строки, классы вычетов, направления — не инвариантны к перестановкам
   строк и столбцов, и первый момент их видит (чётность объясняется наклоном exp(−E[T | профиль]) с точностью ≈ 12 %, ночь 2→3.09).
4. **Только первый момент:** дисперсии и P(T = 0) по типам различны (§Машинная проверка, п. 2); у решений прямоугольники обогащены в 1.3 раза
   при равном E[T] — эффект корреляций, не среднего. Механизм обрывается ровно на k = 4: E[T² | F] — сумма по объединениям пар троек
   (4-, 5-, 6-подмножества многих орбит с недетерминированным счётом).
