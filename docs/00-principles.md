# 00 — Принципы ателье лемм

1. **Нужда первична.** Лемма начинается с вычисления, которое не проходит или повторяется, и с файла-свидетельства.
   «Хочется красивого» — не нужда. Гейт: `need_lint`.
2. **Число до счёта.** Гипотеза — ставка с допуском в `moves/ledger.jsonl` до любого прогона; исход — один из трёх
   (держится / нарушен / не могу измерить); «держится у части» запрещено.
3. **Фальсификация раньше доказательства.** Перебор малых случаев — первым; большинство гипотез умирает здесь, и это дёшево.
4. **Опознание раньше теоремы.** «Известно ли это?» — OEIS, mathlib, ProofWiki, MathOverflow, дип-ресерч. Известное — законный
   выход: нить заканчивается на ссылке, а не на «нашей» лемме.
5. **Доказано — единственная валюта первой оси.** Доказательство + машинная проверка на малых случаях обязательны;
   Lean — по желанию, но каждая лемма в форме, пригодной для формализации.
6. **Противник до приёмки.** Отдельный агент (Opus), «против формы» читается первым; вердикт убит / ранен / устоял.
7. **Обобщение — отдельный цех.** Доказанное для полигона доводится до самой общей формы, которую возьмёт другой, и
   снабжается контрпримером на границе («прямые — да, плоскости — нет»).
8. **Два носителя или честная метка «инструмент».**
9. **Переход = файл, не пересказ.** Всё, что движется между цехами, — файл фиксированной формы; гейт читает файлы.
10. **Ничего не теряется молча.** Недоказанное помечено; неизвестное — `UNSPECIFIED`; двусмысленное — два прочтения.
11. **Один журнал ставок** (`moves/ledger.jsonl`), одна дверь на запись состояния; чтение свободно.
12. **Отрицательный результат — законный выход.** Убитый кандидат с числом дороже живого без числа.
13. **Повторившаяся боль → полевая заметка → правка принципов.**
