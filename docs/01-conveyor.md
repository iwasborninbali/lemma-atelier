# 01 — Конвейер: цеха, артефакты, гейты

| # | Цех | Вход | Пишет только в | Гейт (запускает не автор) |
|---|---|---|---|---|
| 1 | Приёмка нужды | счёт, журнал, чужая статья | `needs/need-NNN.md` | `need_lint`: есть файл-свидетельство, названо чего не хватает |
| 2 | Гипотеза | нужда | строка `prediction` в `moves/ledger.jsonl`, `conj-NNN` внутри need | ставка числом с допуском, `independent_of_target` |
| 3 | Фальсификация | гипотеза | `lemmas/lem-NNN.md` §проверка (перебор малых случаев, код) | контрпример найден → нужда назад с классом контрпримеров; не найден → дальше |
| 4 | Опознание | выжившая гипотеза | `lemmas/lem-NNN.md` §опознание | вердикт «известно как X / частично / не найдено — где искали» |
| 5 | Доказательство | опознанная как ненайденная | `lemmas/lem-NNN.md` §доказательство + §машинная проверка | доказательство полное; проверка кодом на всех случаях до размера k прошла |
| 6 | Противник | лемма | `lemmas/lem-NNN.md` §противник | убит / ранен (что именно) / устоял; без вердикта — не лемма |
| 7 | Обобщение | устоявшая | §общая форма + §граница (контрпример за границей) | форма, которую возьмёт другой; граница названа |
| 8 | Носители | общая форма | §носители | ≥ 2 области или метка «инструмент» |
| 9 | Выпуск | всё зелёное | заметка / ProofWiki / mathlib-PR / Zenodo; `DECISIONS.md` | имя даётся последним |

Петли: контрпример → **дефект** (цех 3/5); аксиома или условие подправлено → **уточнение** (класс контрпримеров назван до следующих
данных); новая нужда из доказательства → **новое** (новая нить). Повторившаяся боль → `docs/field-notes.md` → правка принципов.
